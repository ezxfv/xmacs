# AstroNvim 快捷键与编辑工作流

本文是当前 `nvim/` 配置的快捷键唯一说明源，覆盖项目、文件、Buffer、搜索、批量修改、多光标、Git/Diff、LSP、调试、终端与会话管理。

## 1. 约定与查键

- `SPC`：空格键，即 `<Leader>`。
- `,`：`<LocalLeader>`。
- `C-x`：按住 `Ctrl` 再按 `x`。
- `M-x`：按住 `Alt` 再按 `x`。
- `S-x`：按住 `Shift` 再按 `x`。
- 普通模式：按 `Esc` 后的默认模式。
- 可视模式：用 `v`、`V` 或 `C-v` 选中内容后的模式。

| 快捷键 | 功能 |
|---|---|
| `SPC` | 打开 WhichKey，继续按键可逐层查看映射 |
| `SPC fk` | 搜索所有已注册快捷键 |
| `SPC SPC` | 搜索并执行 Neovim 命令 |
| `:map <键>` | 查看某个键的实际映射 |
| `:verbose map <键>` | 查看映射及其定义来源 |
| `:help <主题>` | 打开 Neovim 帮助 |

> 插件按需加载，因此 LSP、Git、多光标等局部映射只会在对应文件或界面中出现。

## 6. 导航历史、位置栈与 Marks

Neovim 内置多种位置历史。它们解决的问题不同，不应混用：

- **Jumplist**：自动记录跨文件或大跨度导航，用于回到“刚才从哪里跳过来”。
- **Changelist**：自动记录当前文件发生修改的位置，用于回到“刚才在哪里改过”。
- **Marks**：手动保存重要位置，用于稍后精确返回。
- **Last position**：快速返回上次编辑或插入位置。

### 6.1 Jumplist：自动跳转历史

| 快捷键/命令 | 功能 |
|---|---|
| `C-o` | 沿跳转历史后退一项 |
| `C-i` | 沿跳转历史前进一项；部分终端也可用 `Tab` |
| `SPC fj` | 用 Snacks 搜索并选择任意跳转历史位置 |
| `:jumps` | 查看当前窗口的原始 Jumplist 和当前位置 |
| `数字 C-o` | 一次后退指定数量的跳转，例如 `3C-o` |
| `数字 C-i` | 一次前进指定数量的跳转 |

Jumplist 会记录 `gd`、引用跳转、搜索跳转、行号跳转、跨文件 Picker 选择等有意义的导航，不记录普通 `j/k` 移动。它按窗口维护；选择拆分窗口后，每个窗口会继续维护自己的跳转位置。

### 6.2 Changelist：修改位置历史

| 快捷键/命令 | 功能 |
|---|---|
| `g;` | 跳到上一个修改位置 |
| `g,` | 跳到下一个修改位置 |
| `:changes` | 查看当前 Buffer 的修改位置列表 |
| `数字 g;` / `数字 g,` | 一次跨过指定数量的修改位置 |

Changelist 记录的是文本发生变化的位置，不是撤销内容。若需要恢复内容，使用 `u`、`SPC fu` 或 `SPC fU`。

### 6.3 Marks：手动保存位置

| 快捷键/命令 | 功能 |
|---|---|
| `m{a-z}` | 设置当前 Buffer 内的本地 mark，例如 `ma` |
| `m{A-Z}` | 设置可跨文件跳转的全局 mark，例如 `mA` |
| `` `{mark}`` | 精确返回 mark 的行和列，例如 `` `a`` |
| `'{mark}` | 返回 mark 所在行的第一个非空字符，例如 `'a` |
| `` `[`` / `` `]`` | 跳到最近修改或粘贴文本的起点/终点 |
| `` `<`` / `` `>`` | 跳到上一次可视选区的起点/终点 |
| `SPC f'` | 用 Snacks 搜索并选择所有 marks |
| `:marks` | 查看原始 marks 列表 |
| `:delmarks a` | 删除指定 mark |
| `:delmarks!` | 删除当前 Buffer 的全部小写 marks |

### 6.4 最近编辑位置

| 快捷键 | 功能 |
|---|---|
| `gi` | 回到上次退出插入模式的位置并进入插入模式 |
| `g;` | 回到最近一次文本修改位置 |
| `` `.`` | 精确跳到最后一次修改位置 |
| `` `^`` | 精确跳到最后一次退出插入模式的位置 |
| `'.` / `'^` | 跳到对应位置所在行 |
| `Ctrl-6` 或 `C-^` | 在当前文件和上一个文件之间切换 |

推荐用法：连续阅读代码时用 `C-o/C-i`；想从完整历史中任选位置时用 `SPC fj`；追踪刚才修改过的位置时用 `g;/g,`；长期保留的位置使用 marks。

## 8. 多光标与列编辑

当前已安装 `vim-visual-multi`。推荐两种入口：同词多选和垂直多光标。

### 8.1 同词多光标

1. 将光标放在目标单词上。
2. 按 `C-n` 选择当前词；继续按 `C-n` 依次加入下一个匹配。
3. 按 `c`、`s`、`i`、`a` 等进入编辑，所有光标同步修改。
4. 按 `Esc` 退出多光标。

| 快捷键 | 功能 |
|---|---|
| `C-n` | 选择光标下单词；重复按加入下一个匹配 |
| `C-a` | 选择当前单词的全部匹配 |
| `C-x` | 跳过当前匹配并选择下一个 |
| `C-p` | 移除当前选区/光标 |
| `n` / `N` | 多光标模式中移动到下一个/上一个匹配 |
| `Esc` | 退出多光标模式 |

也可以先用可视模式选中任意文本，再按 `C-n` 逐个选择匹配内容。

### 8.2 垂直多光标

| 快捷键 | 功能 |
|---|---|
| `M-j` | 向下一行增加光标 |
| `M-k` | 向上一行增加光标 |

若终端截获 `Alt` 组合键，使用原生列编辑作为稳定替代：

1. `C-v` 进入块选择。
2. 用 `j/k` 选择多行，用 `h/l` 调整列范围。
3. 按 `I` 在每行前插入，或按 `A` 在每行后追加。
4. 输入文本后按 `Esc`，修改会应用到全部选中行。

## 9. 批量搜索与修改

### 9.1 当前文件替换

```vim
:%s/旧文本/新文本/gc
```

- `%`：整个文件。
- `g`：替换每行所有匹配，而不是每行第一个。
- `c`：逐个确认，推荐默认保留。

常用变体：

| 命令 | 功能 |
|---|---|
| `:%s/old/new/gc` | 全文件逐项确认替换 |
| `:%s/old/new/g` | 全文件直接替换 |
| `:'<,'>s/old/new/gc` | 只替换可视选区 |
| `:s/old/new/gc` | 只替换当前行 |
| `:%s/\<old\>/new/gc` | 只替换完整单词 `old` |
| `:%s//new/gc` | 使用上一次搜索模式进行替换 |

### 9.2 多文件批量修改

安全路径是“搜索 → Quickfix → 逐项确认修改”：

```vim
:vimgrep /旧文本/j **/*.{go,lua,ts,py}
:copen
:cdo s/旧文本/新文本/gc | update
```

| 命令/快捷键 | 功能 |
|---|---|
| `:vimgrep /模式/j 文件表达式` | 将跨文件匹配写入 Quickfix |
| `SPC xq` | 打开 Quickfix 列表 |
| `:cnext` / `:cprev` | 下一个/上一个 Quickfix 项 |
| `:cdo 命令` | 对每个 Quickfix 项执行命令 |
| `:cfdo 命令` | 对 Quickfix 涉及的每个文件执行一次命令 |
| `:argdo 命令` | 对参数列表中的所有文件执行命令 |
| `:wall` | 保存所有已修改文件 |

直接无确认跨文件替换前先提交或暂存 Git 变更；否则回滚边界不清晰。

### 9.3 Grug-far 交互式跨文件替换

Grug-far 提供可编辑结果、Diff 预览、文件过滤和替换历史，适合项目级文本迁移。代码符号仍优先使用 LSP rename。

| 快捷键 | 功能 |
|---|---|
| `SPC ss` | 打开工作区搜索替换 |
| `SPC se` | 只搜索当前文件类型 |
| `SPC sf` | 只搜索当前文件 |
| `SPC sw` | 以光标下单词预填搜索 |
| 可视模式 `SPC s` | 以选区预填搜索 |
| Grug-far 中 `,r` | 应用替换 |
| Grug-far 中 `,c` | 关闭替换 Buffer |

推荐先检查结果 Diff 并删除不应修改的结果行，再执行 `,r`。替换后使用 `SPC gd` 审查真实文件改动。

### 9.4 宏：结构相同但文本不同的重复修改

1. 按 `qa` 开始录制到寄存器 `a`。
2. 完成一次修改和移动到下一个目标的操作。
3. 按 `q` 停止录制。
4. 按 `@a` 回放一次，`@@` 再次回放。
5. `10@a` 连续执行十次。

宏适合无法用单个正则表达式描述、但编辑动作高度重复的场景。

## 10. CSV/TSV 表格预览

打开 `.csv` 或 `.tsv` 文件时会自动启用 `csvview.nvim`：异步解析并按列对齐，表头固定显示，编辑原始文本时视图实时更新。默认支持逗号、Tab、分号和竖线分隔符。

| 快捷键/命令 | 功能 |
|---|---|
| `SPC cv` | 打开或关闭当前 CSV/TSV 表格视图 |
| `SPC ci` | 查看当前解析信息与检测到的格式 |
| `Tab` / `S-Tab` | 下一个/上一个字段 |
| `Enter` / `S-Enter` | 下一行/上一行对应字段 |
| 可视/操作模式 `if` | 选择字段内容，不包含分隔符 |
| 可视/操作模式 `af` | 选择整个字段 |
| `:CsvViewEnable delimiter=;` | 使用指定分隔符开启视图 |
| `:CsvViewEnable display_mode=border` | 使用边框模式展示分隔符 |
| `:CsvViewEnable sticky_columns=2` | 固定前两列 |
| `:CsvViewDisable` | 关闭表格视图 |

表格视图使用虚拟文本对齐，不会重写 CSV 内容；保存时仍保存原始分隔格式。

## 14. REST Client 与数据库

### 14.1 从 `.http` 文件发送请求

使用 `rest.nvim`。每个请求用 `###` 分隔，光标放在请求任意一行即可发送。

```http
@baseUrl = https://httpbin.org

### 查询用户
GET {{baseUrl}}/get?id=42
Accept: application/json

### 创建用户
POST {{baseUrl}}/post
Content-Type: application/json

{
  "name": "Eden"
}
```

| 快捷键/命令 | 功能 |
|---|---|
| `SPC rr` | 发送光标所在请求 |
| `SPC rl` | 重发最近一次请求 |
| `SPC re` | 为当前 `.http` 文件选择 `.env` 环境文件 |
| `SPC rE` | 显示当前 `.http` 文件使用的环境 |
| `:Rest run` | 发送光标所在请求 |
| `:Rest run 请求名` | 发送指定名称的请求 |
| `:Rest env set 路径` | 为当前文件指定环境文件 |
| 结果窗口 `H` / `L` | 上一个/下一个结果页 |
| 结果窗口 `?` | 查看结果窗口帮助 |

环境变量文件中的 token、密码不应提交到 Git；项目应将实际 `.env` 加入 `.gitignore`，只提交无密钥的示例文件。

### 14.2 数据库连接与 SQL 执行

使用 `vim-dadbod`、Dadbod UI 和 SQL 补全。已关闭“保存 SQL 文件时自动执行”，所有查询必须显式触发。

| 快捷键 | 功能 |
|---|---|
| `SPC Du` | 打开或关闭数据库 UI |
| `SPC Da` | 添加数据库连接 |
| `SPC Df` | 定位当前数据库查询 Buffer |
| SQL 普通模式 `,e` | 执行光标所在 SQL 语句 |
| SQL 可视模式 `,e` | 执行选中的 SQL |
| SQL 普通模式 `,b` | 执行整个 SQL Buffer |

连接 URL 示例：

```text
postgresql://user:password@host:5432/database
mysql://user:password@host:3306/database
sqlite:/absolute/path/to/database.sqlite3
```

推荐流程：

1. `SPC Du` 打开数据库 UI。
2. 在数据库 UI 中按 `A`，输入连接名称和 URL。
3. 展开连接并打开一个查询 Buffer，或在普通 `.sql` 文件中设置 `$DATABASE_URL`。
4. 将光标放在目标语句内按 `,e`；解析基于 Treesitter SQL 语法节点，不会默认执行整个文件。
5. 需要执行多条语句时先可视选择，再按 `,e`。

> `INSERT`、`UPDATE`、`DELETE`、DDL 等语句会真实修改数据库。插件不会自动添加事务或回滚；对生产库执行前先确认连接和影响范围。

## 21. 推荐工作流速查

### 修改当前符号的所有语义引用

1. 将光标放在符号上。
2. 按 `SPC lr`。
3. 输入新名称并确认。

### 修改当前文件中若干相同文本

1. 光标放在文本上，连续按 `C-n` 选择目标。
2. 用 `C-x` 跳过不应修改的匹配。
3. 按 `c` 输入新文本。
4. 按 `Esc` 完成。

### 完成一次代码验证闭环

1. `SPC xx` 检查当前文件诊断，消除静态错误。
2. `SPC Tt` 运行最小相关测试，必要时 `SPC Td` 调试失败测试。
3. `SPC Tf` 运行当前文件测试，再用 `SPC Tp` 运行项目测试。
4. `SPC Mr` 运行项目 lint/build 任务，用 `SPC Mt` 检查输出。
5. `SPC gd` 打开 Diffview 审查变更。
6. 用 `Tab` / `S-Tab` 浏览文件，在文件面板按 `s` 暂存确认过的文件。
7. `SPC gD` 关闭 Diffview。

### 从诊断定位并修复

1. `SPC cD` 查看工作区诊断。
2. 选择问题后按 `Enter` 跳转。
3. `SPC la` 查看 Code Action。
4. `SPC cf` 格式化并保存。

### 跨文件批量替换

1. 用 `:vimgrep` 建立准确的 Quickfix 集合。
2. `SPC xq` 审核命中范围。
3. 使用带 `c` 的 `:cdo s/.../.../gc` 逐项确认。
4. 检查 `SPC gd` 后再提交。
